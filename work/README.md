# Your work

This folder is a place for your own extra copies and files.

You can change the module's notebooks where they are. Get new materials never overwrites a file you changed. Step 3a of the Your workstation guide explains what it does instead.

Use this folder when you want a second copy, such as a fresh try at a notebook. Keep each copy in a folder for its week, such as `work/Week/03/`. In a terminal, this command copies the Week 3 Introduction there:

```bash
mkdir -p work/Week/03 && cp MN5813/2026-27/Week/03/Introduction.ipynb work/Week/03/
```

The fetch scripts in `Tools/` also write the assessment data here, into `data/`. The `.gitignore` file in this folder keeps the fire-brigade data out of your [commits](../MN5813/2026-27/Guides/glossary.md#term-commit).
